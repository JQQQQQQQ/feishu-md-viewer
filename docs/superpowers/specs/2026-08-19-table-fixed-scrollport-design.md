# 表格固定滚动视口与左侧展示层设计

## 目标

宽表保持原生横向滚动条的外观和固定轨道长度，同时在向右滚动的初始阶段显示原本会被裁掉的左侧表格内容。普通正文、标题和手动目录开关不得移动。

## 交互规则

1. 表格总宽度未超过“标题起点到浏览器右侧 10%”的可用宽度时，按实际宽度显示，不显示横向滚动。
2. 超出可用宽度时，固定宽度的滚动视口显示原生横向滚动条。滚动条轨道始终等于该视口宽度。
3. 向右滚动时，先在左侧展示层显示被视口裁掉的内容；展示距离等于滚动距离，最大为标题起点到浏览器左侧 10% 的距离。
4. 左侧展示距离达到上限后，继续向右滚动只改变主滚动视口中的表格内容。
5. 向左滚动时，先回收主视口滚动，再逐步收回左侧展示层；表格缩小到不溢出时，展示层和滚动状态均清零。
6. 仅当左侧展示层处于展开状态时隐藏目录；目录隐藏不改变正文主容器的位置。

## 组件结构

```text
FeishuTable 外框（边框与选中轨道）
├── 左侧展示层（只读渲染或裁剪副本；最大到视口左侧 10%）
├── 固定滚动视口（唯一原生 overflow-x: auto 容器）
│   └── 主表格
└── 固定表头克隆
```

外框不参与横向滚动，也不随滚动扩宽。原生滚动条只属于固定滚动视口，因此长度稳定。左侧展示层与主表格共享列宽和内容快照，但不接管编辑、复制或单元格选择事件；这些事件仍由主表格负责。

## 状态与数据流

- `scrollLeft`：固定滚动视口的真实原生滚动位置。
- `leftReveal`：`min(scrollLeft, maxLeftReveal)`。
- `mainScrollLeft`：`max(0, scrollLeft - maxLeftReveal)`，用于主表格显示区域。
- `maxLeftReveal`：标题起点减去浏览器宽度的 10%。

滚动事件只更新上述派生状态和展示层裁剪宽度；不得修改外框宽度、正文容器边距或原生滚动条尺寸。

## 验收与测试

1. 窄表无滚动条、外框等于表格宽度。
2. 宽表的原生滚动条宽度在任意滚动位置保持不变。
3. 在 `maxLeftReveal` 内右滚 10px，左侧展示层增加 10px，正文位置不变。
4. 超过上限后，展示层宽度固定，主表格内容正常向左滚动。
5. 向左回滚、缩窄列宽、切换目录都能正确恢复，且不闪烁。
6. 固定表头、整行整列选择、文本选择和复制回归通过。
