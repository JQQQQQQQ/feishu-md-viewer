# Mermaid 流程图预览体验设计

## 1. 目标

在现有 Mermaid 预览弹窗的基础上，重构为更接近图片预览和文档阅读的沉浸式画布：图表打开后定位稳定、画布背景干净、普通滚轮不误触缩放、工具栏按需出现，并支持快速关闭。

本次设计只针对 Mermaid 预览弹窗，不改变正文 Mermaid 卡片、源码编辑入口、SVG/PNG 导出逻辑，也不引入新的 Mermaid 渲染器。

## 2. 已确认的交互决策

| 维度 | 决策 | 具体行为 |
| --- | --- | --- |
| 工具栏显隐 | B2 | 工具栏默认隐藏；鼠标进入画布底部热区、工具栏自身或通过键盘操作时展开；离开后延迟隐藏 |
| 滚轮与拖拽 | C2 | 普通滚轮只做上下滚动；Shift + 滚轮做横向滚动；普通拖拽不抢占文本/画布滚动，按住空格后拖拽平移 |
| 初始定位 | D2 | 首次测量完成后再显示最终视图；短图完整适应并居中；超宽/超长图不缩到不可读，从安全起点开始并允许滚动查看 |
| 画布视觉 | E2 | 画布沿用正文主题背景，不使用点阵；图表保留细边框、圆角和轻阴影；深色主题使用对比变量而非纯黑阴影 |
| 关闭方式 | F1 | 点击遮罩空白处关闭；点击图表、滚动区和工具栏不关闭；Esc 关闭；关闭后焦点恢复到正文“预览”按钮 |
| 工具栏内容 | G1 | 只放“适应、100%、缩小、放大、关闭”等预览控制；源码复制与 SVG/PNG 导出继续保留在正文 Mermaid 工具栏 |

## 3. 交互状态

### 3.1 打开阶段

1. `MermaidToolbar` 取得已经渲染的 SVG，打开预览状态。
2. `MermaidPreviewModal` 在首次布局测量前保持不可见或显示轻量加载占位，避免先显示错误位置再跳动。
3. 读取 SVG 的 `width`、`height` 或 `viewBox`，结合画布 client 尺寸计算 D2 缩放值。
4. 应用缩放和滚动初始值后再显示画布；初始焦点放在关闭按钮，保证键盘用户可以直接按 Esc。

### 3.2 工具栏状态

- `toolbarVisible` 默认由底部热区和焦点状态决定，不影响画布尺寸。
- 底部热区为画布底部约 56px 的透明区域，进入热区展开工具栏；离开工具栏后延迟约 180ms 收起。
- 工具栏展开/收起只改变 opacity/transform/pointer-events，不修改 canvas padding、scrollWidth 或图表布局，避免滚动条闪动。
- 键盘操作（`+`、`-`、`0`、`f`、`Escape`）发生时保持工具栏短暂可见并更新缩放文本。
- 预览弹窗不再使用占据布局高度的顶部控制栏；画布占据主要区域，标题作为无障碍标签保留，关闭、适应和缩放控制统一放在底部悬浮栏中。

### 3.3 滚轮与拖拽

- 画布设置 `overscroll-behavior: contain`，阻止弹窗滚动事件穿透正文。
- 普通 wheel 不调用缩放；浏览器默认的纵向滚动保留给画布。
- `Shift + wheel` 映射为横向滚动；在不支持 `deltaX` 的环境中使用 `deltaY` 作为横向增量。
- 只有空格键按下且指针在画布内时才进入平移拖拽；拖拽开始后使用 pointer capture，结束/取消时释放。
- 图表内部的文本选择和链接点击不能被普通 pointer down 阻止；空格平移状态下才 `preventDefault`。

### 3.4 缩放锚点

- 工具栏按钮以画布视口中心为锚点，保持用户当前阅读区域，不重置到左上角。
- `100%` 恢复实际尺寸并将图表定位到 D2 安全起点；`适应` 重新测量当前画布并完整应用 D2 规则。
- 缩放范围保留现有 25%～400% 约束，步进沿用现有 1.2 倍。
- 缩放后通过一次布局帧更新滚动边界，禁止连续 setState/scroll 写入造成滑块闪动。

### 3.5 关闭与焦点

- overlay 处理点击：事件目标等于 overlay 本身时调用 `onClose`，dialog、canvas、toolbar 内部点击不关闭。
- Esc 关闭并阻止事件继续影响正文。
- 关闭时清理拖拽、工具栏计时器和 wheel 监听；下一帧把焦点恢复到 `MermaidToolbar` 的预览按钮。
- 预览弹窗保持 `role="dialog"` 和 `aria-modal="true"`，按钮保留可读的中文/英文 aria-label。

## 4. 视觉规范

- overlay 继续使用半透明遮罩和轻微背景模糊，但避免过重的黑色蒙层。
- dialog 作为承载容器保留圆角；画布不再额外铺点阵，背景直接使用 `var(--feishu-bg-page)`。
- 图表外框使用 `var(--feishu-bg-content)`、`var(--feishu-border-lighter)` 和主题化阴影；外框尺寸严格包住 SVG，不额外制造右侧或底部空白。
- 工具栏为底部中央的半透明胶囊，按钮高度至少 30px，焦点环使用品牌色，深色主题下按钮和边框满足可读对比度。
- 工具栏悬浮在画布上方，不参与文档流；画布底部为工具栏预留透明热区，但不改变 SVG 的可滚动宽高。
- `prefers-reduced-motion: reduce` 下取消工具栏和弹窗动画，显隐直接切换。

## 6. 验收标准

1. 打开任意 Mermaid 图时，不出现先偏移再居中的闪动；短图完整居中，宽图起点稳定且文字可读。
2. 普通滚轮只让预览画布上下滚动，不改变缩放比例；Shift + 滚轮可以横向查看宽图。
3. 按住空格拖拽可以平移画布；未按空格时不阻断图表内文本/链接交互。
4. 鼠标移到窗口底部后工具栏出现，工具栏出现/消失不改变滚动条长度和图表位置。
5. 点击“适应”和“100%”后滚动边界稳定，滑块不闪动；缩放按钮以当前视口中心为锚点。
6. 点击遮罩空白处或按 Esc 可以关闭；点击画布、滚动区、工具栏不会误关闭；关闭后焦点回到正文预览按钮。
7. 浅色和深色主题中画布、图表外框、工具栏均与正文背景协调，无纯黑块或低对比边界。
8. 现有 Mermaid 渲染、正文预览、SVG/PNG 导出和图片预览回归测试继续通过。

## 7. 风险与缓解

- **浏览器 wheel 事件差异**：使用 `deltaMode` 归一化增量并在 Chromium 浏览器中增加 E2E 验证。
- **布局帧竞态**：统一由 `requestAnimationFrame` 执行滚动边界更新，组件卸载时取消待执行帧。
- **工具栏遮挡图表**：工具栏使用浮层定位，不参与 canvas 布局；底部热区只作为触发区。
- **SVG 尺寸缺失**：继续使用现有 `viewBox` 和默认尺寸回退，异常 SVG 仍显示可操作的错误/空状态。
