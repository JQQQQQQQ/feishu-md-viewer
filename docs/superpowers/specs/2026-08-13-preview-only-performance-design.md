# 彻底预览版性能优化设计

## 目标

将 Feishu MD Viewer 调整为只读预览扩展，移除编辑功能及其构建依赖，降低首屏运行成本和最终构建体积，同时保持现有阅读体验。

## 产品范围

### 保留功能

- Markdown 标题、段落、列表、引用、Callout、表格、代码块和图片预览；
- 目录导航、标题定位、标题折叠和滚动状态；
- 表格单元格文字选择、Excel 式区域选择、TSV/HTML 复制；
- Mermaid 图表预览、缩放、拖拽、导出和错误降级；
- 图片预览、复制按钮、主题、字号、阅读进度；
- 本地 `file://`、GitHub、GitLab Markdown 阅读。

### 移除功能

- 阅读/编辑/源码模式切换；
- 双击进入编辑；
- Milkdown WYSIWYG 编辑器；
- 源码编辑器；
- Mermaid 源码编辑和 Mermaid 编辑器弹窗；
- 自动保存、文件写回、保存按钮和编辑相关文件访问逻辑；
- 编辑器专用 CSS、编辑状态和编辑模式滚动恢复。

## 架构调整

### App 渲染入口

`App` 固定使用 `read` 模式，只渲染 `MarkdownReadView`。移除编辑器的 `lazy import`、编辑分支、编辑状态回调、保存状态传递和编辑快捷键。

启动时不再依赖 store 的编辑模式进行渲染；若旧设置或旧持久化状态中存在 `edit/source`，统一归一化为 `read`。

### TopBar

移除编辑/源码模式按钮以及保存控件，只保留侧栏、主题、字号、预览相关操作。顶部栏不显示“编辑”“源码”“保存”等不可用入口。

### Store 与文件访问

删除或收缩仅服务于编辑的状态和 action：`mode`、`setMode`、编辑滚动恢复、脏状态、文件句柄、自动保存和写回逻辑。保留阅读态需要的文档内容、主题、字号、目录和预览设置。

如果删除 store 字段会影响已有测试或公共调用，先保留类型兼容但禁止进入编辑分支；最终以构建引用分析为准，不能让编辑器依赖通过生产入口继续打包。

### Mermaid

阅读态保留 Mermaid 图表渲染、预览、缩放、拖拽、导出和错误降级。移除 Mermaid 源码编辑入口、`MermaidEditor` 和仅用于编辑的编辑器样式。

### 依赖与样式

移除仅被编辑能力使用的 Milkdown 相关依赖及其入口引用；删除编辑器组件和编辑专用样式文件。清理后运行构建产物分析，确认没有残留编辑器 chunk。

## 兼容性

- 旧设置中的 `previewLockEnabled` 不再决定是否显示编辑入口；预览版始终只读；
- 旧设置或旧状态中的 `mode: edit/source` 启动时归一化为 `read`；
- Markdown 内容只读，不再提供写回源文件的操作；
- 不改变现有阅读态 CSS、目录行为、表格复制行为和 Mermaid 预览行为；
- 不修改 Markdown 解析结果和标题 ID 生成逻辑。

## 性能验收

实现前后记录：

1. `dist` 总体积；
2. 最大 JS chunk 和主要入口 chunk；
3. 构建产物中是否仍出现 Milkdown、ProseMirror、编辑器入口或编辑器样式；
4. App 首屏是否只创建阅读组件；
5. UI 中是否不存在编辑、源码和保存入口。

不设定未经基线测量的绝对体积目标，但必须证明编辑相关代码不再从生产入口加载，并且构建体积相对当前基线不回退。

## 测试策略

### 单元测试

- App 只渲染阅读视图，不渲染编辑器和源码编辑器；
- TopBar 不渲染编辑、源码和保存控件；
- 旧模式状态启动后归一化为 `read`；
- Mermaid 阅读态预览、导出和错误降级仍通过；
- 表格、目录、Markdown 解析和图片预览回归通过。

### 构建验证

```bash
TMPDIR=/tmp npm test
npm run typecheck
npm run build
npm run perf:bundle
git diff --check
```

### 手动验收

加载最新 `dist` 后打开本地 Markdown 和 GitHub Markdown，确认：

- 页面直接进入阅读态；
- 顶部没有编辑/源码/保存按钮；
- 双击正文不会进入编辑；
- 目录、表格复制、Mermaid 预览和图片预览仍可用；
- 旧设置不会把页面切换到编辑态。
