# 阅读即编辑体验交付计划

## 目标

把当前 Markdown 阅读器升级为“阅读即编辑”的文档体验：用户点击编辑后，页面不跳变、不换壳、不降级，仍然像飞书文档一样阅读，只是在当前位置获得编辑能力。

最终效果：

- 阅读态是高质量飞书风格 Markdown 文档。
- 编辑态不是另一个页面，而是当前文档直接可编辑。
- 阅读态和编辑态的标题、段落、列表、引用块、表格、代码块、Mermaid、图片视觉一致。
- 工具只在用户需要时出现，避免一进入编辑就满屏控件。
- 高级用户仍然可以进入源码模式批量修改 Markdown。
- 每个阶段都有浏览器自动化验证，避免后续改动反复破坏体验。

## 当前结论

历史上体验奇怪的根因是阅读态和编辑态使用两套渲染体系：

- 阅读态：`MarkdownRenderer` + 自定义飞书风格组件。
- 编辑态：`WysiwygEditor` + Milkdown / ProseMirror。

两套体系的 DOM、样式、复杂块能力不同，所以点击编辑时会产生“页面变了”的感知。

当前主路径已收敛为 Milkdown 文档层：阅读态、编辑态共用 `WysiwygEditor`，源码模式使用独立的 `SourceModeEditor`，旧 `MarkdownRenderer / MarkdownEditor` UI 组件已移除。

## 交付原则

1. **先稳定外壳，再打磨细节**
   - 先保证切换不跳、布局不变、滚动位置不变。
   - 再逐步对齐块样式和复杂块编辑。

2. **保留已验证能力**
   - Mermaid 预览、表格选择复制、代码块复制和高亮、图片预览等已有能力不能回退。

3. **复杂块局部编辑**
   - Mermaid、代码块、表格、图片、Callout 不应该迫使用户切换到源码模式。
   - 默认仍显示高质量预览，hover 后出现局部操作。

4. **源码模式是高级入口**
   - 默认编辑入口是 WYSIWYG。
   - 源码模式用于批量修改、排查 Markdown、处理复杂文本，不作为普通编辑体验的替代品。

5. **每个阶段都要可验收**
   - 类型检查、单元测试、构建、浏览器真实验证缺一不可。

## 交付阶段

### Phase 1：无跳变编辑框架

状态：已完成第一版。

目标：

- 点击编辑后页面不换壳。
- 正文宽度、横向位置、顶部工具区位置不变。
- 滚动位置保持。
- 阅读进度条不再因为进入编辑态而消失。

已完成内容：

- 统一 `App.tsx` 中阅读态和编辑态的正文外层结构。
- 根节点增加 `data-mode` 与 `feishu-viewer--reading / feishu-viewer--editing`。
- 新增 `useModeScrollRestore`，切换模式前记录滚动位置，切换后恢复。
- 顶部保存区在阅读态保留不可见占位，避免右侧工具横向跳动。

验收标准：

- 浏览器实测 `scrollDelta = 0`。
- 浏览器实测正文 `x`、`width` 差异为 `0`。
- 浏览器实测顶部操作区 `x`、`width` 差异为 `0`。
- 编辑态存在 `.ProseMirror`，阅读进度条仍存在。

### Phase 2：阅读态与编辑态视觉统一

状态：已完成第一版。

目标：

- 同一份 Markdown 在阅读态和编辑态下看起来像同一个文档。
- 消除 Milkdown 默认样式带来的编辑器感。
- 块级元素视觉差异收敛到可接受范围。

交付内容：

- 对齐标题：
  - 字号、行高、间距。
  - `scroll-margin-top`。
  - 标题下内容层级缩进。
- 对齐段落和列表：
  - 行高。
  - 上下间距。
  - 嵌套列表缩进。
- 对齐表格：
  - 列线展示。
  - 表头背景。
  - 单元格 padding。
  - 行 hover。
  - 编辑选区样式。
- 对齐引用块和 Callout：
  - 普通引用块样式一致。
  - Note / Tip / Warning / Important / Caution 等彩色 Callout 在编辑态保持同等质感。
- 对齐代码块：
  - 背景、圆角、padding。
  - 语言标签。
  - 复制按钮位置。
  - 语法高亮策略。
- 对齐图片：
  - 最大宽度、圆角、预览入口。
- 对齐 Mermaid：
  - 容器、hover 工具、预览入口。

已完成内容：

- 编辑态正文复用阅读态外层宽度和页面结构。
- 编辑态标题、段落、列表、表格、引用块、代码块基础视觉已对齐。
- 编辑态标题层级缩进已通过动态 scoped 样式实现，不污染 ProseMirror 文档模型。
- 编辑态表格列线已稳定展示。
- 编辑态普通引用块已对齐阅读态蓝色引用样式。

关键技术任务：

- 新增共享文档视觉层 `document.css`，逐步从 `markdown.css` 和 `wysiwyg.css` 抽出共用规则。
- 编辑态只保留 ProseMirror 相关差异，例如光标、选区、当前块焦点态。
- 为编辑态补齐标题层级缩进，避免阅读态有层级而编辑态没有层级。

验收标准：

- 阅读态和编辑态截图中，正文宽度、标题、段落、表格、引用块、代码块视觉一致。
- 表格列线在编辑态稳定展示。
- 编辑态引用块不再退化成普通 blockquote。
- 编辑态代码块不再显得像原生编辑器块。

### Phase 3：低干扰编辑工具

状态：已完成第一版，后续继续扩展块级工具。

目标：

- 编辑工具只在用户需要时出现。
- 工具栏不抢焦点、不移动光标、不误隐藏。

交付内容：

- 文本选择后出现浮动格式工具栏：
  - 加粗。
  - 斜体。
  - 删除线。
  - 行内代码。
  - 链接。
  - 标题级别。
  - 引用。
  - Callout 类型。
- 块 hover 后显示左侧块操作柄：
  - 插入块。
  - 转换块类型。
  - 删除块。
  - 后续支持拖动排序。
- 表格 hover 后显示行列工具。
- 工具栏检测范围扩大，鼠标可以从正文移动到工具栏。
- 点击工具按钮后：
  - 不移动文本光标。
  - 不把光标跳到第一段。
  - 不立即隐藏工具栏。
  - 连续点击 5 到 10 次仍稳定。

已完成内容：

- 浮动工具栏已支持 5 个基础按钮：加粗、斜体、删除线、行内代码、链接。
- 点击工具按钮时先恢复用户原始选择范围，再执行 Milkdown 命令。
- 工具栏按钮改为 `mousedown` 执行，避免按钮获得焦点导致编辑器选择丢失。
- 点击按钮后主动让编辑器失焦，减少文本光标在工具栏操作期间的干扰。
- 点击按钮后工具栏保持显示，直到选择变化或鼠标离开相关区域。
- 链接编辑从浏览器原生 `prompt` 改为工具栏内输入层，避免连续点击时弹出系统窗口打断操作。

验收标准：

- 连续点击粗体、斜体、删除线、链接等按钮不会失效。
- 点击按钮后工具栏保持，直到鼠标移出或选择取消。
- 文本光标不因为点击工具按钮跳转。
- 表格工具和文本工具互不抢状态。

### Phase 4：复杂块局部编辑

状态：已完成第一版，后续继续做真实浏览器验收和细节打磨。

目标：

- Mermaid、代码块、表格、图片、Callout 在编辑态保持预览品质，同时具备局部编辑能力。

Mermaid 交付内容：

- 默认显示渲染图。
- hover 图表时右上角显示：
  - 预览。
  - 编辑。
  - 复制源码。
  - 导出 SVG / PNG。
- 预览弹窗支持：
  - 居中显示。
  - 鼠标所在位置缩放。
  - 更慢、更细腻的滚轮缩放。
  - 拖动平移。
- 编辑弹窗支持：
  - Mermaid 源码编辑。
  - 实时预览。
  - 友好错误提示。
  - 保存后写回原 Markdown。

已完成内容：

- 编辑态 Mermaid 默认显示渲染图，选中源码时可回到源码编辑。
- Mermaid 工具支持预览、复制源码、导出 SVG、导出 PNG、编辑源码。
- 预览弹窗支持适应窗口、100%、按钮缩放、鼠标位置滚轮缩放、拖动平移。
- Mermaid SVG 注入前统一执行边界扩展和 DOMPurify SVG 清洗。

代码块交付内容：

- 编辑态保持语法高亮。
- 复制按钮固定右上角。
- 语言选择稳定。
- 点击代码内容进入编辑。
- 失焦后恢复文档化展示。

表格交付内容：

- 支持单元格编辑。
- 支持整列选择复制。
- 支持矩形选择复制。
- 支持增删行列。
- 支持清空内容。
- 删除第一行和清空第一行逻辑稳定。

Callout 交付内容：

- 支持从普通引用转换为 Callout。
- 支持 Note / Tip / Warning / Important / Caution。
- 支持编辑态类型切换。
- 阅读态与编辑态样式一致。

已完成内容：

- 编辑态选中引用块时显示 Callout 类型切换控件。
- 支持在普通引用、Note、Tip、Warning、Important、Caution 间转换。
- 表格行列工具支持格式化、复制、清空内容、删除行列。

验收标准：

- 复杂块编辑不需要全量切源码模式。
- Mermaid 编辑失败不会破坏原内容。
- 表格边界操作有测试覆盖。
- 代码块高亮、复制、语言选择在阅读态和编辑态都稳定。

### Phase 5：源码模式

状态：已完成基础版，后续可升级为 CodeMirror 6。

目标：

- 提供高级 Markdown 源码编辑能力，但不影响默认阅读即编辑体验。

交付内容：

- 已将旧双栏 `MarkdownEditor.tsx` 收敛为独立 `SourceModeEditor`。
- 当前基础版使用 textarea，后续再使用 CodeMirror 6 替换。
- 支持：
  - Markdown 语法高亮。
  - 行号。
  - 搜索。
  - 自动换行。
  - 快捷键。
  - 可选实时预览。
- 模式扩展为：
  - `read`
  - `edit`
  - `source`

验收标准：

- 源码模式适合批量修改 Markdown。
- 从源码模式切回阅读/编辑模式不丢内容。
- 滚动位置尽量保持。
- 大文档输入不卡顿，预览更新有 debounce。

- 浏览器验证：

  - 顶部工具区不横向跳。
  - 表格列线存在。
  - 工具栏连续点击不失效。
  - Mermaid 预览可缩放、可拖动。

- 视觉检查：
  - 阅读态和编辑态关键元素 computed style 对比。

## 架构整理计划

### 目标目录结构

```text
src/viewer/components/Markdown/
  MarkdownRenderer.tsx
  FeishuComponents.tsx

  Editor/
    DocumentEditor.tsx
    SourceModeEditor.tsx
    EditorModeSwitch.tsx
    FloatingFormatToolbar.tsx
    BlockActionHandle.tsx
    hooks/
      useEditorSync.ts
      useModeScrollRestore.ts
      useSelectionToolbar.ts

  CodeBlock/
    CodeBlock.tsx
    EditableCodeBlock.tsx
    highlighter.tsx

  Mermaid/
    MermaidBlock.tsx
    MermaidPreviewDialog.tsx
    MermaidEditorDialog.tsx

  Table/
    FeishuTable.tsx
    EditableTable.tsx
    tableSelection.ts
```

### 样式整理

```text
src/viewer/styles/
  document.css      # 阅读态和编辑态共享的文档视觉规范
  markdown.css      # MarkdownRenderer 的结构补充
  wysiwyg.css       # ProseMirror / Milkdown 编辑差异
  editor.css        # 源码模式、弹窗编辑器、旧编辑器迁移
```

### 文件规模约束

- TypeScript / TSX 文件尽量不超过 300 行。
- 每个目录尽量不超过 8 个直接文件。
- 新能力优先进入子目录，不继续堆在 `components/Markdown` 顶层。

## 最终验收清单

产品体验：

- 点击编辑后页面不跳、不换壳。
- 阅读态和编辑态视觉一致。
- 标题层级缩进一致。
- 表格列线、选择、复制、行列操作稳定。
- 代码块有高亮、语言、复制按钮。
- Mermaid hover 显示按钮，预览支持缩放和拖动，编辑支持源码写回。
- 引用块和 Callout 可读、好看、可编辑。
- 图片可预览，后续可替换。
- 源码模式可用但不打扰默认编辑体验。

工程质量：

- 无明显样式重复失控。
- 无编辑态和阅读态长期漂移的结构。
- 无模式切换导致的内容丢失。
- 自动化验证覆盖核心交互。
- 构建产物可同步到扩展目录并自动重载验证。

## 交付顺序

1. 完成 Phase 2 的标题层级结构对齐。
2. 抽出 `document.css`，收敛阅读态和编辑态共享视觉规则。
3. 完成 Phase 3 的低干扰编辑工具。
4. 完成 Phase 4 的 Mermaid、代码块、表格、Callout 局部编辑。
5. 完成 Phase 5 的源码模式。
6. 持续补 Phase 6 自动化验证。

```bash
pnpm typecheck
TMPDIR=/tmp pnpm test
pnpm build
```

浏览器验证使用 Windows Playwright 扩展连接，检查真实 GitHub Markdown 页面中的扩展渲染结果。
